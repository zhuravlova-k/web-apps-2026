# Афіша культурних подій міста

Вебзастосунок (SPA на Vue 3) із локальним Node.js/Express-сервером, збереженням обраних подій в IndexedDB та аудитом безпеки (варіант 5).

## Локальний сервер (Практична робота №14)

Проєкт переведено на клієнт-серверну архітектуру з локальним Express-сервером (`server/server.js`), який роздає статику з теки `public/` і надає REST-ендпоінти замість зовнішнього API:

- `GET /api/events` — локальний перелік культурних подій із `server/data/events.json`;
- `GET /api/events/:id` — деталі однієї події за `id` або `404` із JSON-помилкою;
- невідомі маршрути `/api/*` повертають `404` у форматі JSON.

### Запуск локально

```bash
cd server
npm install
npm start
```

Після запуску застосунок доступний за адресою `http://localhost:3000`.

## Безпека та аудит (Практична робота №15)

Проведено аудит клієнтської та серверної частин застосунку «Афіша культурних подій міста» (варіант 5):

1. **Захист від XSS (`name`, `location`):**
   - Пошук по проєкту підтвердив відсутність `innerHTML`, `outerHTML`, `v-html`, `document.write` та `eval`.
   - Для демонстрації вразливості тимчасово відтворено небезпечний рендер поля `location` через `v-html`: введення `<img src=x onerror="alert('XSS')">` викликало виконання скрипту (`alert('XSS')`).
   - Після повернення стандартної інтерполяції Vue 3 (`{{ ... }}`, під капотом `textContent`) той самий рядок відображається як звичайний текст без виконання HTML.
   - Додано сувору валідацію й нормалізацію вхідних даних (`normalizeEvent`, `isValidISODate`, обмеження довжини, білий список категорій) та безпечне кодування параметрів маршрутів (`encodeURIComponent` / `decodeURIComponent`).

2. **Аудит локальних сховищ (`IndexedDB` / `localStorage`):**
   - Сховище `savedEvents` має низький рівень ризику: містить лише публічні поля подій (`id`, `name`, `category`, `date`, `location`, `engName`) без паролів, токенів чи персональних даних.
   - Усунено зайве дублювання записів у `localStorage` при доступній `IndexedDB`: після міграції ключ `appItems` очищується, а `localStorage` використовується лише як резервний режим.

3. **Секрети та HTTP-заголовки:**
   - Захардкоджених API-ключів, паролів або токенів у коді немає.
   - На сервері вимкнено заголовок `X-Powered-By`, додано `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY` та `Referrer-Policy: no-referrer`; клієнт переведено на production-збірку Vue 3 (`vue.global.prod.js`).

4. **Розгортання з HTTPS:**
   - Для публічного розгортання клієнтської частини обрано хостинг із HTTPS за замовчуванням (**GitHub Pages**, **Netlify** або **Vercel**), а для Node.js-бекенда — платформи з автоматичним TLS (**Render** / **Railway**), що захищає трафік від перехоплення (MITM).
